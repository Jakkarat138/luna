# น้องลูน่า — โปรแกรมจำลองดูแลเด็ก SLE

เว็บแอปภาษาไทยสำหรับจำลองการดูแลเด็กป่วย SLE เมื่อต้องออกไปกลางแจ้ง

## ความสามารถ

- เตือนเมื่อออกแดดโดยยังไม่ได้ใส่อุปกรณ์ป้องกัน
- เช็กลิสต์ครีมกันแดด เสื้อแขนยาว หมวก และแว่นกันแดด
- เมื่อเตรียมอุปกรณ์ครบ สามารถออกแดดได้โดยไม่มีเสียงเตือน
- จำลองอากาศร้อนขึ้นและแจ้งให้ไปหลบในที่ร่มทันที
- รองรับคอมพิวเตอร์และโทรศัพท์มือถือ
